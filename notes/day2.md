# Day2 学习笔记
## ✅ 已经掌握
1. 变量与四种数据类型：
    - int：整数，例：90
    - float：小数，例：85.5
    - str：字符串（文字，要用引号包裹），例："优秀"
    - bool：布尔，只有两个值 True / False，首字母必须大写
2. type() 函数：查看变量是什么类型
3. 赋值符号 `=` 和比较符号 `==` 区分：
    - `=`：赋值，把右边的值装进左边变量
    - `==`：判断两边是否相等，结果是 True / False
4. if / elif / else 分支判断语法：
    - if、elif、else 这一行末尾**必须写英文冒号 `:`**
    - 冒号下一行代码，一定要缩进（Tab）
    - 多分支规则：从上往下依次匹配，命中一个就直接跳出，不会继续判断后面条件
5. 逻辑运算符：
    - and：并且，两边条件同时成立才是 True
    - or：或者，任意一边成立就是 True

# Day1 + Day2 合并学习笔记
## ✅ 已经掌握
1. print() 打印函数
- 作用：把内容输出到终端上，是我们看程序结果的窗口
- 写法：
  - print(内容)
  - 文字字符串必须加英文引号 `print("你好")`
  - 数字可以直接写 `print(99)`
- 读音：print /prɪnt/
- 小坑：括号、引号必须是英文符号

2. variable 变量
- 作用：用来存数据（数字、文字都可以）
- 语法：变量名 = 值
  例：`score = 82`
- `=` 是赋值，不是等于；`==` 才是判断两边是否相等

3. 4种基础数据类型 + type()
- int：整数，如 90
- float：小数，如 85.5
- str：字符串（文字），引号包裹，如 `"优秀"`
- bool：布尔，只有 True真，成立/ False假，不成立，首字母大写
- type(变量)：查看这个变量是什么类型

4. def 自定义函数
- def 用来打包一段代码，做成一个工具
- 定义：`def introduce():` 末尾带冒号，下一行缩进写代码
- 只写def不会自动运行，**必须调用** `introduce()` 才会执行

5. if / elif / else 分支判断（重点）
- if、elif、else 行结尾必须写英文冒号 `:`
- 冒号后面的代码，必须缩进（Tab）
- 执行规则：从上往下依次匹配，命中一个分支，执行完就跳出，不再往下判断
- 逻辑关键字
  - and：并且，两边条件同时成立才为True
  - or：或者，任意一边成立就为True

3. 语法、应用
day3
- input：输入（动词 / 函数名，接收用户在终端输入内容）
- string：字符串，就是文字、文本内容
- index：索引，下标，从 0 开始用来定位字符串里的某一个字符
- slice：切片，截取字符串其中一段内容
- length：长度，这里对应 `len()`，统计一共有多少个字符
- `/` 除完带小数
- `//` 只要商，丢掉小数
- `%` 只要剩下的余数
- `**` 求几次方
day4 
- 字符串方法：`strip()` 去首尾空格、`upper/lower` 大小写、`replace` 替换、`split` 切分
- 数字运算符：`//` 整除、`%` 取余、`**` 乘方
- `float(input())` 转换：字符串不能直接算数学，必须先转数字
- BMI 公式：体重 ÷ 身高 ²（分子分母别颠倒）
- 多分支判断：从大到小写要配 `>=`，不能塞中间值
- 变量作用域：变量定义在 `else` 里面，外层用不到


1. `TypeError: unsupported operand type(s) for /: 'str' and 'str'` → input 拿到的是字符串，必须先 float
2. `NameError: name 'BMI' is not defined` → 变量写在 else 内部，if 分支走不到就不存在；后面要用的变量提到外层
3. BMI 公式颠倒 → 分子是体重，分母是身高平方
4. `msg.strip.upper()` 报错 → 方法必须带括号 `strip()`，才能链式调用
