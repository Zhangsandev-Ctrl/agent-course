# Day2 学习笔记 · 变量与分支

## 一、变量与四种基础数据类型

| 类型 | 含义 | 示例 |
|---|---|---|
| `int` | 整数 | `90` |
| `float` | 小数 | `85.5` |
| `str` | 字符串，文字必须加引号 | `"优秀"` |
| `bool` | 布尔，只有 `True` / `False`，首字母必须大写 | `True` |

- `type(变量)`：查看变量是什么类型。
- `=` 是赋值（把右边的值装进左边变量）；`==` 是判断两边是否相等，结果是 `True` / `False`。
- 变量名自己起，见名知义。

## 二、if / elif / else 分支判断

```python
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
else:
    print("继续努力")
```

- `if`、`elif`、`else` 行末尾必须写英文冒号 `:`，下一行必须缩进。
- 从上往下依次匹配，命中一个分支执行完就跳出，不再判断后面条件。
- 逻辑运算符：`and`（两边都成立才 True）、`or`（任意一边成立就 True）。
- 区间判断必须用 `and`：`score >= 80 and score <= 89`。写成 `or` 条件恒成立，后面分支永远跑不到。
- 三元表达式：`text = "是" if flag else "不是"`。
- `if is_student:` 等价于 `if is_student == True:`。

## 三、易错点

1. `print("你好，我叫{name}")` 少了 `f`：变量不会替换，必须写成 `f"你好，我叫{name}"`。
2. 中文冒号、中文引号会直接报语法错误，代码里的符号必须是英文。
3. 缩进不对，代码归属混乱（`if` 和 `else` 的代码块必须各自缩进）。
4. `def` 定义函数后忘记调用，代码不会执行。
5. 区间判断误用 `or`，逻辑失效。

## 四、D3 补充：字符串基础

1. `input()`：接收键盘输入，返回值**永远是字符串 `str`**。
2. 字符串拼接 `+`、重复 `*`。
3. 索引 `[0]`：从 0 开始取字符；`[-1]` 取最后一个。
4. 切片 `[1:3]`：左闭右开，取到下标 1、2。
5. `len()`：统计字符数量。
6. `type()`：查看变量类型。
7. 转义符 `\n` 换行。
8. f-string 格式化写法。

## 五、D4 补充：字符串方法与运算符

- 字符串方法：`strip()` 去首尾空格、`upper()` / `lower()` 大小写、`replace()` 替换、`split()` 切分。
- 数字运算符：`+ - * /`，以及 `//` 整除、`%` 取余、`**` 乘方。
- `/` 除完带小数，`//` 只要商，`%` 只要余数。
- `float(input())`：字符串不能直接做数学运算，必须先转数字。
- BMI 公式：体重 ÷ 身高²（分子是体重，分母是身高平方，别颠倒）。
- 多分支判断：从大到小写要配 `>=`，不能把中间值塞在条件里。
- 变量作用域：变量定义在 `else` 里面，外层用不到，后面要用的变量提到外层。

## 六、D3 / D4 词表

| 英文 | 含义 |
|---|---|
| `input` | 输入，接收用户在终端输入的内容 |
| `string` | 字符串，文字、文本内容 |
| `index` | 索引 / 下标，从 0 开始定位字符 |
| `slice` | 切片，截取字符串的一段 |
| `length` | 长度，对应 `len()` |

## 七、D3 / D4 报错

1. `TypeError: unsupported operand type(s) for /: 'str' and 'str'` → `input` 拿到的是字符串，必须先 `float()`。
2. `NameError: name 'BMI' is not defined` → 变量写在 `else` 内部，`if` 分支走不到就不存在；后面要用的变量提到外层。
3. BMI 公式颠倒 → 分子体重、分母身高平方。
4. `msg.strip.upper()` 报错 → 方法必须带括号 `strip()`，才能链式调用。
