# Day2 学习笔记
## ✅ 已经掌握
1. 变量与四种数据类型：
    - int：整数，例：90
    - float：小数，例：85.5
    - str：字符串（文字，要用引号包裹），例："优秀"
    - bool：布尔，只有两个值 True / False，首字母必须大写
2. type() 函数：查看变量是什么类型
3. 赋值符号 `=` 和比较符号 `==` 区分：
    - `=`：赋值，把右边的值装进左边变量
    - `==`：判断两边是否相等，结果是 True / False
4. if / elif / else 分支判断语法：
    - if、elif、else 这一行末尾**必须写英文冒号 `:`**
    - 冒号下一行代码，一定要缩进（Tab）
    - 多分支规则：从上往下依次匹配，命中一个就直接跳出，不会继续判断后面条件
5. 逻辑运算符：
    - and：并且，两边条件同时成立才是 True
    - or：或者，任意一边成立就是 True

## ❓ 待解决疑问
1. 英语基础弱，这些英文单词记起来吃力
> 解决办法：不用背拼写，先认意思，写代码的时候多敲几次，写多了自然记住；面试的时候能说清作用就行，不用默写单词。
2. 内置函数不熟悉（比如 type()）
> 解决办法：我们后面会慢慢接触，不用一次性全部背完，遇到一个记一个，放到错题本里。
3. 应用还不熟练
> 解决办法：多写小测试代码，改不同数值跑一遍，看输出变化，慢慢建立手感。
