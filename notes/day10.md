# day10 笔记：字符串常用方法 + 列表/字典配套方法
> 说明：方法格式：`变量.方法()`，不同类型变量能调用的方法不一样

## 一、字符串 str 方法
### 1. 空白处理
| 方法 | 作用 |
| ---- | ---- |
| `.strip()` | 删除**左右两边**空白（空格、回车`\n`、制表符`\t`），中间空格保留 |
| `.lstrip()` | 只删除左侧开头空白 |
| `.rstrip()` | 只删除右侧末尾空白 |
```python
s = "  abc  "
print(s.strip())  # 'abc'
print(s.lstrip()) # 'abc  '
print(s.rstrip()) # '  abc'

2. 判断类（返回 True / False）
方法                作用
.startswith("xxx")	判断字符串是否以 xxx 开头
.endswith("xxx")	判断字符串是否以 xxx 结尾
.isalpha()	        是否全部是字母
.isdigit()	        是否全部是纯数字字符串 ⚠️ 不支持小数、负号
.isalnum()	        是否只有字母 + 数字，无符号、空格
.isspace()	        是否全部是空白字符

3. 分割、拼接
方法	                作用
.split(分隔符)	        按指定符号切割字符串，返回列表；不传参数默认按空白分割
.splitlines()	        按换行符\n切割，适合多行文本
.join(可迭代对象)	    将列表内元素拼接成字符串，和 split 反向

4. 替换、大小写转换
方法	             作用
.replace(old, new)	old = 要替换的旧内容，new = 替换后的新内容，全部匹配项都会替换
.upper()	        全部转大写
.lower()	        全部转小写
.title()	        每个单词首字母大写
5. 查找统计
方法	        作用
.find("子串")	查找子串下标，找不到返回 - 1，不报错
.index("子串")	查找子串下标，找不到直接抛出异常
.count("子串")	统计子串出现次数
6. 对齐填充（了解）
方法	                作用
.center(宽度,填充符)	居中
.ljust(宽度,填充符)	    左对齐
.rjust(宽度,填充符)	    右对齐


二、列表 list 常用方法（账本高频）

- `.append()`：在列表末尾追加元素
- `.pop(idx)`：按下标删除元素，并且返回被删掉的值
- `.remove(值)`：删除第一个匹配该值的元素
- `.sort()`：原地排序
- `.reverse()`：原地反转列表
- `.index()`：查找元素下标
- `.count()`：统计元素出现个数

三、字典 dict 常用方法

- `.keys()`：获取全部 key
- `.values()`：获取全部 value
- `.items()`：拿到 (key,value) 元组，用于 for 循环遍历
- `.get(key, 默认值)`：安全取值，key 不存在不会报错
- `.update()`：批量更新字典

四、文件对象方法（with open 打开文件）

- `.read()`：读取全部内容
- `.readline()`：读取一行
- `.write()`：写入字符串
- `.close()`：关闭文件，with 上下文管理器会自动调用，不用手动写
