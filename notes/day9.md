# D9 个人账本｜问题 + 答案（更新版）

1. 问：`choice` 是什么意思？
答：`choice` 是自定义变量，用来保存用户在菜单输入的内容，程序通过它判断用户选择哪一个功能。`input()` 获取到的内容是字符串，所以判断的时候写 `"1"`、`"2"`，不是数字 1、2。
2. 问：报错 `TypeError: unsupported operand type(s) for +: 'int' and 'str'` 是什么原因？
答：意思是**整数和字符串不能直接相加**。`input()`拿到的内容默认是字符串，如果没有用`int()`/`float()`转为数字，拿去做加减计算就会报这个错。
3. 问：`isdigit()` 是什么意思？
答：`isdigit()` 是字符串自带方法，用来判断这个字符串是不是全部由数字字符组成。返回 True 代表全是数字，False 代表包含字母、符号。
局限：只能识别整数，**识别不了小数点、负数**。
4. 问：`str` 是什么意思？
答：`str` 是 string（字符串）的简写，就是带引号的文字。比如 `"3000"` 类型是字符串，不能直接计算；`int` 是整数，可以用来加减。
5. 问：变量名 `money_str` 为什么要加 `_str`？
答：`_str` 不是 Python 语法强制要求的，只是我们自己加的标记。用来提醒自己：这个变量存的是字符串版本的金额，还没有转成数字，方便区分，避免写代码混淆。
6. 问：输入小数 `10000.34` 的时候，`isdigit()` 判断失败，怎么支持小数金额？
答：`isdigit()` 不识别小数点，改用 `try-except` 异常捕获。尝试把输入转成`float`，整数、小数都能正常通过；如果输入字母、乱码，进入 except 分支友好提示，程序不会崩溃。
7. 问：`f"{income:.2f}"` 是什么作用？
答：格式化输出，`.2f` 代表把数字固定保留 2 位小数，记账的时候金额展示更整齐规范。
8. 问：`.append()` 这个啥意思？
答：`append()` 是列表 list 自带的方法，作用是**往列表的末尾追加一个元素**。
在咱们账本里，就是把新的收支字典记录，加到账目列表`record_list`最后面。
要点：直接修改原列表，一次只能加一个元素，默认加到末尾。

# 错题摘录（error_book.md）

✅ 坑 1：`input()` 返回值永远是字符串，字符串不能直接和数字相加，必须转 int 或者 float
✅ 坑 2：`isdigit()` 只适合纯整数校验，不支持小数点、负数
✅ 坑 3：变量命名小习惯：`xxx_str` 代表字符串版本，用来校验；转换后的数字才用来计算
✅ 坑 4：`try-except` 适合兼容整数、小数的输入校验，非法输入不会直接崩溃
✅ 坑 5：`.append()` 是列表追加元素，原地修改列表，不是生成新列表
